# Swarajya: Shivaji's Legacy

A real-time bullet-heaven action game, grounded in 17th-century Maratha history: drive a historical commander — Shivaji Maharaj, Tanaji Malusare, Bajiprabhu Deshpande, or Netaji Palkar — around a real-time arena with a virtual joystick, auto-attacking weapons (Talwar Strike, Wagh Nakh Throw, Watch Tower Archer, Loyal Mavlas, Rann Shinga) fight off waves of Mughal and Adilshahi forces, and you walk over dropped Valor and Swarajya (Hon) to level up mid-campaign and grow stronger. Each ~3-minute campaign banks Swarajya into **Raigad Fort**, the persistent hub between runs, where you strengthen your Armory, unlock new weapons, chase achievements, and Renew the Oath to prestige for a permanent multiplier on all future campaigns.

The history is treated with respect: real forts, real weapons, real companions of Shivaji Maharaj. Enemy units are deliberately generic ranks (Mughal Scout, Adilshahi Skirmisher, Siege Commander, etc.) rather than named historical individuals, so no real person is turned into a repeatable video-game kill.

Packaged as an Android app for the Play Store via [Capacitor](https://capacitorjs.com/), wrapping a plain HTML/CSS/JS game with no build step of its own.

## Project layout

```
game/            The entire game. Open game/index.html directly in any browser to play/develop.
  index.html
  css/style.css
  js/            Load order matters — see the <script> tags in index.html.
  assets/characters/   Hand-illustrated companion sprites (SVG source + rasterized PNG).
android/         Generated by `npx cap add android` — a standard Capacitor Android/Gradle project.
store-assets/    Master icon art + export-size checklist for Play Store submission.
docs/            Play Store publishing checklist + privacy policy placeholder.
```

## Local development

No build tooling is required for the game itself. Just open it in a browser:

```
open game/index.html          # macOS
xdg-open game/index.html      # Linux
```

Or serve it locally (recommended for realistic testing, since some browsers restrict `localStorage` under `file://`):

```
npx http-server game -p 8080
# then visit http://localhost:8080
```

## Building the Android app

1. Install dependencies:
   ```
   npm install
   ```
2. Generate the native Android project (first time only):
   ```
   npx cap add android
   ```
3. Sync web assets into the native project (run after every change to `game/`):
   ```
   npx cap sync
   ```
4. Open in Android Studio to build/run/sign:
   ```
   npx cap open android
   ```
   Or build a debug APK from the CLI:
   ```
   cd android && ./gradlew assembleDebug
   ```

**Before you ship a real build**, you must supply your own:
- `appId` in `capacitor.config.json` — currently left as `com.bladehunter.idle` (the placeholder from before this history reskin) purely so the already-generated `android/` project didn't need its package directory structure rebuilt by hand. Change it to a package name you actually own in Play Console before publishing — this is permanent once published, and also requires updating `android/app/build.gradle`'s `applicationId` and moving `MainActivity.java` to match the new package path.
- A real AdMob App ID and Rewarded Ad Unit ID (replace the placeholders in `capacitor.config.json`, `android/app/src/main/AndroidManifest.xml`, and `game/js/ads.js`), and set `AdMob.initializeForTesting` to `false` in `capacitor.config.json`.
- A signing/upload keystore (generate locally or in CI secrets — **never commit it**; `.gitignore` already excludes `*.keystore`/`*.jks`).
- A publicly hosted privacy policy URL for the Play Console listing — `docs/PRIVACY_POLICY.md` is a starting draft; GitHub Pages is a free way to host it from this same repo.

See `docs/PUBLISHING.md` for the full Play Console submission checklist.

## Ads

Rewarded video ads are **opt-in only** — no interstitials, no banners, no forced ads during play. Three placements, all in `game/js/ads.js`:
- **War Preparation** (Raigad Fort screen) — start a campaign with weapons +2 levels and the XP bar 30% full.
- **Revive** (death screen) — continue a campaign once after falling, at 50% HP.
- **Double Rewards** (results screen) — double the Swarajya banked from the campaign just finished.

In a plain desktop browser (no Capacitor/AdMob available), these buttons render disabled so the game is fully playable ad-free during development.

## Save data

Progress autosaves to `localStorage` under the key `bladeHunterIdle_save_v1` (kept from before this history reskin — renaming it would silently wipe existing players' saves for no functional benefit, since it's never shown to the player). No account, no network calls, no data leaves the device.
